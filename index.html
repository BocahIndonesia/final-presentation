Smart-NIDS

ML-Powered API

Sebuah web API untuk menganalisa file PCAP dengan bantuan model Machine Learning yang dilatih dengan dataset CICIDS-2018 dan proses data preprocessing yang hati-hati.

Kontribusi Penelitian

Tidak hanya menggunakan teknik murni analisis distribusi terhadap data yang digunakan untuk praproses data, melainkan model yang diimplementasikan ke sebuah aplikasi.

Tiga Model ML

Tiga model yang dilatih dengan algoritma Random Forest , AdaBoost dan Gradient Boosting yang masing- masing memiliki performa yang tinggi.

Tahapan
Penelitian

Pemilihan Dataset

Dataset CICIDS-2018 dipilih karena tersedianya CICFlowMeter-v3 sebagai tool untuk melakukan konversi.

Data Preprocessing

Analisis secara intensif dilakukan terhadap distribusi data untuk memilih dan mengubah data pada variabel

Pelatihan dan Evaluasi

Semua model yang dilatih mendapatkan performa yang bagus terutama yang dilatih dengan algoritma Random Forest.

Deployment

Smart-NIDS ini merupakan aplikasi web tipe REST API, dibuat dengan FastAPI dan bantuan dari tool CICFlowMeter-v3.

Hasil Penelitian

Menemukan
Tahapan Preprocess dengan Analisis Distribusi

Preprocess data dilakukan dengan melakukan analisis intensif terhadap dataset, distribusi data adalah kunci dari tahap preprocess data yang dilakukan pada penelitian ini.

Melatih
Model ML dengan Performa yang Tinggi

Tiga model dengan performa yang tinggi berhasil dilatih, model yang dilatih dengan algoritma Random Forest mendapatkan performa paling tinggi, sedangkan AdaBoost paling rendah.

Meluncurkan
Aplikasi REST API

REST API bernama Smart-NIDS lahir dari penelitian ini, ketika aplikasi ini online, menganalisa file PCAP menjadi lebih mudah.

INTERESTING ANALYSIS

Multicollinearity

Multicollinearity perlu dihapus, variabel-variabel yang memiliki Pearson Correlation Coefficient lebih/sama dengan 0,9 harus dihapus.

Identical Data

Ada 6 variabel yang memiliki kesamaan distribusi dan data, yaitu: Fwd PSH Flags, FIN Flag Cnt, SYN Flag Cnt, RST Flag Cnt, URG Flag Cnt dan ECE Flag Cnt.
